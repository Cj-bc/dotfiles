# Global notes

Language- and tool-specific notes live in dedicated files so they only get
read when relevant. Do NOT inline that content here — keep this file a thin
index of conditional pointers.

- **When working with the Flix language**, read `~/.claude/flix/` first:
  - `~/.claude/flix/language-idioms.md` — syntax, testing (`@Test`/`flix test`), effect handlers, regions/Refs, numeric suffixes.
  - `~/.claude/flix/util-json.md` — the `Util.Json` stdlib (parse + serialize JSON).
